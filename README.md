# Instance Info

Небольшое веб-приложение на Flask, которое показывает, **какая именно
копия (реплика) приложения обработала запрос**. Нужно для того, чтобы
наглядно видеть работу балансировщика нагрузки, когда приложение запущено
в нескольких экземплярах.

## Стек

- Python 3.12, Flask
- Redis — общее хранилище счётчиков для всех реплик

## Локальный запуск (без Docker)

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Запустите Redis любым удобным способом.
3. Задайте переменные окружения (см. `.env.example`) и запустите:
   ```
   python app.py
   ```

Приложение слушает **порт 5000**.

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `REDIS_HOST` | хост Redis | `localhost` |
| `REDIS_PORT` | порт Redis | `6379` |
| `INSTANCE_NAME` | имя реплики, которое показывает приложение | hostname машины/контейнера |

## Маршруты

| Маршрут | Описание |
|---|---|
| `GET /` | HTML-страница: имя реплики, счётчики, статистика по репликам, заголовки запроса |
| `GET /whoami` | имя реплики простым текстом (удобно для `curl` в цикле) |
| `GET /stats` | JSON: общее число обращений и разбивка по репликам |
| `POST /reset` | обнуляет статистику в Redis |
| `GET /slow?seconds=2` | отвечает с задержкой (максимум 10 секунд) |
| `GET /health` | проверка живости приложения и доступности Redis |

## Счётчики

- **Локальный счётчик** хранится в памяти процесса конкретной реплики и у
  каждой реплики свой.
- **Общий счётчик и статистика по репликам** хранятся в Redis, поэтому
  одинаковы для всех реплик.
